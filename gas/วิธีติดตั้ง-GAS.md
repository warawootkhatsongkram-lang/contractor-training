# วิธีติดตั้ง GAS — บันทึกผลอบรมลง Google Sheet (ทำครั้งเดียว ~5 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `ผลการอบรมผู้รับเหมา` (ไม่ต้องสร้างแท็บ/หัวตารางเอง ระบบสร้างให้ตอนบันทึกครั้งแรก)
2. ใน Sheet → เมนู **Extensions (ส่วนขยาย) → Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` ทิ้ง → วางโค้ดทั้งหมดจากไฟล์ `gas/Code.gs` → กด 💾 Save
4. (ทดสอบ) เลือกฟังก์ชัน `testDoPost` → **Run** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … → Allow)
   → กลับไปที่ Sheet ต้องเห็นแท็บ `ผลการอบรม` มีแถวทดสอบ 1 แถว (ลบแถวนั้นทิ้งได้)
5. **Deploy → New deployment** → ⚙️ เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** ← ต้องเป็น Anyone เท่านั้น ไม่งั้นหน้าเว็บจะได้หน้า login แทนผลลัพธ์
6. กด Deploy → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
7. เปิดไฟล์ `index.html` หาบรรทัด `const GAS_URL = '';` → วาง URL ระหว่าง `''` → บันทึก → อัปขึ้น GitHub
8. เช็ค: เปิด URL `/exec` ในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"contractor-training",...}`

## ⚠️ แก้โค้ด GAS ภายหลัง
กด Save อย่างเดียว **ไม่พอ** — URL เดิมยังรันโค้ดเก่า ต้องไปที่
**Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** (URL เดิมไม่เปลี่ยน)

## ความปลอดภัยของข้อมูล
- ข้อมูลส่วนบุคคล (ชื่อ เบอร์โทร) อยู่ใน Google Sheet ของเดย์เท่านั้น ไม่อยู่บน GitHub
- อย่าแชร์ Sheet แบบ "ทุกคนที่มีลิงก์" — แชร์เฉพาะคนที่ต้องตรวจ (จป.)
- URL `/exec` รับได้เฉพาะการ "เพิ่มผลอบรม" อ่านข้อมูลใน Sheet ผ่าน URL นี้ไม่ได้
