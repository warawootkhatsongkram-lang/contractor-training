# ระบบอบรมความปลอดภัยผู้รับเหมา

ผู้รับเหมาสแกน QR → ลงชื่อ → อ่านสไลด์อบรมตามประเภทงานบนมือถือจนครบทุกหน้า → กดยืนยัน → ผลถูกบันทึกลง Google Sheet ให้ จป.วิชาชีพ ตรวจก่อนออกใบอนุญาตทำงาน (Work Permit)

ฝ่ายความปลอดภัย · บริษัท ชูศิลป์ กรุ๊ป เทรดดิ้ง จำกัด

## ไฟล์ในระบบ
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าอบรม (ลงชื่อ / เลือกหลักสูตร / อ่านสไลด์ / ยืนยันผล) — ทดสอบระบบด้วย `index.html?test=1` |
| `qr.html` | โปสเตอร์ QR สำหรับพิมพ์ A4 (QR สร้างจากลิงก์ของเว็บนี้อัตโนมัติ) |
| `slides/` | รูปสไลด์ทีละหน้า (แปลงจาก PDF) |
| `ข้อมูล/` | PDF ต้นฉบับ |
| `gas/` | โค้ด Google Apps Script + วิธีติดตั้ง |
| `tools/convert_slides.py` | แปลง PDF → รูป WebP |

## แก้/เพิ่มเนื้อหาอบรม
1. วาง PDF ใหม่ใน `ข้อมูล/` แล้วแก้ตาราง `COURSES` ใน `tools/convert_slides.py`
2. `pip install pymupdf pillow` แล้วรัน `python tools/convert_slides.py`
3. แก้ `COURSES` ใน `index.html` ให้จำนวนหน้า (`pages`) ตรงกับที่สคริปต์แจ้ง
4. ถ้าเพิ่มรหัสหลักสูตรใหม่ ต้องเพิ่มใน `ALLOWED_COURSES` ของ `gas/Code.gs` และ Deploy New version ด้วย
